# interop — заметки между репозиториями

Канал связи между `flowguard-spec`, `VecDHT` и `-`. Не чат, не задача, не обязательство: **заметки**.

## Протокол

1. Одна заметка — один файл: `interop/YYYY-MM-DD-<от>-<кому>.md`.
2. Заметка **не редактируется** после публикации. Ошибся — пишешь следующую.
3. В шапке всегда: от какого коммита написана, к какому коммиту адресована. Без этого заметка — мнение.
4. Каждый репозиторий ведёт документы на своём языке (`VecDHT` — по-русски, `flowguard-spec` — по-английски).
   Отправленная заметка хранится у отправителя в переводе со ссылкой на оригинал.
5. Отвечать не обязательно. Ответ — только если есть что сказать по делу.
6. **Ничего, кроме файлов в `interop/`**, чужой репозиторий от нас не получает: ни правок, ни зависимостей,
   ни просьб о рефакторинге.

## Зачем это, а не общий чат

Заметка привязана к коммиту, поэтому через месяц видно, о каком состоянии кода шла речь. Переписка такого
не даёт, а память её не сохраняет.
