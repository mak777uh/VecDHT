## Режим работы

- Одна карточка плана = одна ветка мысли: разведка → `H-XXXX` + `E-XXXX` с порогом **до** прогона →
  код → прогон с логом в `lab/logs/` → закрытие с вердиктом → коммит → push. Не начинай вторую карточку,
  не закрыв первую.
- Разведку делай чтением кода, не догадкой: прежде чем написать «в коде так», прочитай всю цепочку
  данных (откуда поле берётся), а не одну функцию.
- Каждая bash-команда: `cd /c/Users/Admin/vecdht-work/vecdht && export PATH=/c/Users/Admin/mingw64/bin:$PATH && …`.
- До и после тяжёлого прогона — `bash lab/disk-report.sh`. Порог: свободно ≥ 15 000 МБ. `cargo clean`
  только с объявления владельцу.
- Docker, forge, anvil локально нет — их карточки идут через CI (`.github/workflows/`), установку
  инструментов сначала объявить владельцу.
- Никаких ключей, секретов и транзакций в сеть без явной команды владельца. Sepolia — только с его «да».
- Отчёт владельцу после каждой карточки: простыми словами, по-русски, что сделано, число из лога, что
  не проверено, % готовности v1 (оценка, не замер).
