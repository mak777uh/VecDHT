# VecDHT

P2P-семантический поиск и rendezvous агентов: узел публикует интент (embeddings + короткий
текст), другой узел находит его по смыслу, без обязательного центра. Чистый Rust, ядро протокола
реализовано один раз — языковые привязки вызывают его, а не переписывают байтовые форматы.

Спецификация: [docs/VecDHT-SPEC-v8.md](docs/VecDHT-SPEC-v8.md). Она же — источник чисел и
контрактов в коде; там же приложение «что удалено из v7.5 и почему».

## Статус

v8 пишется по этапам P0–P7 из §20 спеки. В `main` пока только те crate, которые собираются и
тестируются: байтовый слой протокола (`vecdht-wire`) и слой детерминизма (`vecdht-crypto`),
77 тестов зелёные. Остальные добавляются этапами — в `workspace.members` попадает только готовое,
чтобы `cargo test` на `main` всегда проходил.

| Crate | Что содержит | Этап |
|---|---|---|
| `crates/vecdht-wire` | fixed-LE кодек с TLV-хвостом, кадр, таблица `Kind`, все сообщения, `NodeCert` (§5) | P2 — готов |
| `crates/vecdht-crypto` | int8-квантование, идентификаторы, publish-PoW, Ed25519, пороговая проверка кредашиалов (§4, §6, §11) | P2 — готов |
| `crates/vecdht-artifact` | артефакт сети: manifest + замороженные центроиды (§7.1) | P2 |
| `crates/vecdht-index` | IVF-арена, WAL, снапшот-барьер, GC без wall-clock (§8, §10) | P3 |
| `crates/vecdht-node` | приём записей, admission, эпохи, членство, репликация (§9, §11–§13) | P4–P5 |
| `crates/vecdht-embed` | контракт инференса и канонизация эмбеддингов, candle за фичей (§6.2) | P0 |
| `crates/vecdht-cli` | `artifact init`, `publish`, `find`, `serve` | P6 |
| `sdk/vecdht-py` | PyO3-привязка; Python не кодирует и не подписывает сам (§5.1) | P6 |

## Сборка

```
cargo test            # unit-тесты + golden-векторы
cargo clippy --all-targets -- -D warnings
```

`cargo` требует C-линковщика, потому что `blake3` собирает нативный код, а на `x86_64-pc-windows-gnu`
его ещё и надо найти. На Windows два варианта: установить Visual Studio Build Tools (toolchain
`msvc`), либо положить рядом полный standalone mingw-w64 и поставить его `bin` в `PATH` раньше
любого другого gcc — сборки из-под miniconda не хватает (нет `libws2_32.a`, линкер 2.25 не тянет
современный libstd).

## Что здесь не так, как в v7.5

Кратко, детали и измерения — в спеке:

* маршрутизация: SimHash-префикс заменён coarse-квантизатором из артефакта, шардов ровно 64;
* идентичность: `PeerId` остаётся тем, что выводит libp2p, роль даёт подписанный `NodeCert`;
* индекс: PQ удалён, хранится int8-вектор, recall перестаёт быть функцией квантования;
* PoW: Argon2id удалён, blake3 с привязкой nonce к `(owner, shard, epoch, slot, expiry)`;
* детерминизм: фиксированная точка Δ=1/127 вместо обещания bit-identical float-инференса;
* приватность: формулировка честно ослаблена — index-node читает то, что держит (honest-but-curious).
