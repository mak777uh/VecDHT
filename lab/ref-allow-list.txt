# lab/ref-allow-list.txt — исключения стража разрешимости имён (`python lab/repo-review.py check`).
#
# Что здесь попадает. Страж требует, чтобы каждый дескриптор `H-XXXX`, `E-XXXX`, `ADR-XXXX`,
# `L-XXXX` в закоммиченной разметке разрешался в артефакт: карточку
# `lab/hypotheses/H-XXXX[-slug].md`, `lab/experiments/E-XXXX[-slug].md`,
# `lab/decisions/ADR-XXXX[-slug].md` или запись `L-XXXX` в `lab/library/index.jsonl`.
# Номер, под которым артефакта ЕЩЁ НЕТ, но который уже занят очередью, — не битая ссылка,
# а бронь: он живёт здесь. Всё остальное — находка класса `refs-dangling`, она валит выход.
#
# Правила списка (их проверяет сам страж, а не память вызывающего):
#   1. одна строка — один идентификатор; после `#` обязана быть ПРИЧИНА с местом брони
#      (файл и пункт, где номер заявлен). Без причины запись ничего не разрешает:
#      номер остаётся разрывом и печатается строкой `СПИСОК refs-allow-list`.
#   2. номер снимается отсюда в том же коммите, где заведён артефакт (иначе запись
#      печатируется как `REVIEW_ALLOW_LIST_UNUSED` — список не должен обрастать).
#   3. сюда нельзя класть адрес, которого нет в очереди: опечатка в номере — это правка
#      документа, а не бронь. Проверка адреса — строка, называющая номер как кандидат,
#      резерв или голову очереди.
#   4. номера, зарезервированные как кандидаты решений, перечислены таблицей
#      `lab/decisions/OPEN-QUESTIONS.md` (п. 3, 7, 9…26, 29…34); ссылки вида `ADR-00NN`
#      в README и PITCH на НЕпринятый кандидат — правка документа (волна 1 аудита),
#      а не право номера: страж по этой строке не судит, какой документ обязан меняться.
#
# Источники строк: `lab/notes/AUDIT-2026-10-25-repo-spec-readme.md` находка 5 и B6,
# `lab/repo-review.py` (`check_descriptors`), самопроверка `python lab/repo-review.py refselftest`.
