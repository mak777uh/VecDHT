# H-0116 — ledger обязан читать блок, а не весь append-only лог

## Боль

`lab/ledger.py` на закрытом зелёном цикле `E-0114` печатает `LEDGER_OK=0` и выход 1: он читает весь
append-only лог, складывает красный контроль посадки (`V9CTL_BRIDGE_EXIT=1`) и собственный прошлый
`LEDGER_EXIT=1` в список провалов. Прибор, который должен делать расход видимым, сам производит
ложный красный — и `workspace-verify.sh` возвращает 1 на зелёном дереве.

## Зачем это нужно

`ROADMAP.md` H1 требует, чтобы тег запускал `bash lab/workspace-verify.sh <run-id>` с выходом 0, а
`docs/PLAN-v1.md` ставит Т1 первой карточкой именно потому, что без неё нельзя отличить «гейт
красный» от «прибор красный». Это не косметика: ложный красный уже стоил одного разбора в `E-0114`
(ДИАГНОЗ-2).

## Источники до эксперимента

`python lab/sources.py hunt "log ledger last run block control exit false failure" --github -n 3`
вернул три статьи arXiv, не относящиеся к разбору логов (стохастический MPC, weakly-hard control,
distributed ledger), и ноль GitHub-репозиториев. Refusal записан в `prior_art`: переносить чужой
разбор без замера — догадка. Внутренний источник формы — helper `lab/e0114-run.sh`, шаг 8b: он уже
вырезает последний блок `workspace-verify` через `awk`, но `ledger` затем читает весь `all.log`.

## Решение по рубрике Lean

`пространство: да` (строки лога конечны), `без_времени: да`, но `для_всех: нет` — утверждение о
конкретном приборе и двух конкретных файлах, а не инвариант над всеми состояниями; `дешевле_стенда:
нет` — сам прибор и есть стенд. Четыре «да» не набраны, модель Lean не обязательна; отказ назван.

## Ожидаемый эффект

Инварианты: ложный красный исчезает, красный контроль остаётся красным. Стоимость: без изменений
(Python, секунды). Память: без изменений. Операционная цена: `workspace-verify.sh` перестаёт
возвращать 1 на зелёном дереве.

## Границы

Не утверждает, что любой чужой лог разобран правильно: граница блока — строка `########## `; лог без
такой строки считается одним блоком. Не проверяет `workspace-verify.sh` целиком — только подачу
логов в `ledger`. Не проверяет Rust-код и продуктовые гейты.
