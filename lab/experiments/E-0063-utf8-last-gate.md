# E-0063 — UTF-8-ветка `session::verify_response` как порядок (§12.4): последний гейт цепочки и два имени отказа для битого UTF-8 в двух полях

## План прогона

Оракул `crates/vecdht-node/tests/utf8_last_gate.rs`, helper `lab/e0063-run.sh` (структура
секций как в зелёных `e0061`/`e0062`: BUILD `--no-run` → RUN `--nocapture` → ИНВЕНТАРЬ →
КОНТРОЛЬ `-p vecdht-node`; helper исполняет команду целиком — урок `e0049`). Живого узла
нет: кадры `IntentTextResponse` собираются напрямую (издатель O, ожидаемый E, подписант F;
модель «гранит», текст «abcdef»), мутации — in-place байты тела (битый текст [0xFF,0xFE]
под честной и чужой подписью, чужой вид, без подписи, 1000/999 байт, битая строка
`model_version` 0xD0→0xFF) плюс подписывающий конец `sign_response`. Часы не участвуют.
Лог: `lab/logs/e0063-all.log` (append-only). Пороги (0)…(9) заморожены в `H-0063` до
первого замера; коммит пре-регистрации пушится до измерений. Верификация воркспейса —
`lab/workspace-verify.sh E-0063`.
