# E-0156 — два литерала `none` не считаются равенством фактов

## Вопрос

Отличает ли хоть один прибор в носителях `lab/e*-run.sh` «факт есть» от «факта нет»? `grab` печатает
непустое `none`, когда факта нет, поэтому `[ -n "$v" ]` молчание пропускает, а `[ "$a" = "$b" ]` при
двух молчаниях истинно. Разведка перед карточкой: 28 сравнений двух переменных, и ровно одно —
`lab/e0146-run.sh:80` — сравнивает два факта, каждый из которых может быть `none`. Вердикт `E-0146`
не отозван только потому, что в его логе значения клеток — числа (`lab/logs/e0146-all.log:71`).

## Порог

Заморожен в `lab/expectations/e0156.tsv` до первого официального прогона. Вердикт — только по его
фактам: на пине нет реестра и единственная пара названа находкой (код 1); после правки 140 носителей,
28 сравнений, 1 пара, реестр называет `e0146:80` причиной, находок 0, код 0; посадки незащищённой

посадок прибора отбиваются; продукт не тронут; два прогона на неизменном дереве совпадают.

## Результат

sentinel-способность — консервативная оценка присваиваний, а не поток данных. Исторический сайт
`e0146:80` назван реестром, а не исправлен: закрытый носитель задним числом не правится.
