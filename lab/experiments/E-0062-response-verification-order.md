# E-0062 — порядок проверок `session::verify_response` (§12.4) и немедленные отказы входа цели (§12.3): непокрытые `TextError::WrongKind`/`Malformed`

## План прогона

(структура секций как в зелёных `e0060`/`e0061`: BUILD `--no-run` → RUN `--nocapture` →
ИНВЕНТАРЬ → КОНТРОЛЬ `-p vecdht-node`; helper исполняет команду целиком — урок `e0049`).

«abcdef», модель «гранит», версия 7) и его мутациях (чужой табличный вид с подписью и без,
вид 0xFE, усечение, `sig_len` 63, отсутствие подписи при ложном владельце, ложный ожидаемый
владелец E при честном и при испорченном тексте, пере-подпись чужим ключом F, 1001 байт
текста при O и при E) плюс `sign_response` с 1001 байтом; путь цели — живой `serve_request`
с чужим адресатом при пустом `present` (11), мусорным `present` (12), таблично чужим видом
в `present` (13), пустым `present` (14) и живым приёмом F0 (15). Часы не двигаются:
`now_bucket = 0` во всех ветках (урок `E-0060`). Лог: `lab/logs/e0062-all.log`

пре-регистрации пушится до измерений. Верификация воркспейса — `lab/workspace-verify.sh
