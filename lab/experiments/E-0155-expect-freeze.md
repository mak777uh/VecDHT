# E-0155 — заморозка таблиц ожиданий: страж против подменённого ожидания

## Вопрос

Краснит ли какой-нибудь прибор подмену таблицы ожиданий после коммита пре-регистрации? Разведка
`OQ п. 93` ответила «нет»: 19 из 58 таблиц на `f0e0378` не совпадают с коммитом, добавившим их
H-карточку, и ни один страж над этим не краснел. Карточка `H-0155` заводит прибор и базовую линию
исторических нарушений.

## Порог

Заморожен в `lab/expectations/e0155.tsv` до первого официального прогона. Вердикт — только по его
фактам: до правки базы нет и 19 нарушений молчат; после правки ноль необъяснённых, все 19 названы
базой, подменённый байт, удалённая таблица и мёртвая строка базы краснеют, вне git — код 2, шесть
посадок прибора отбиваются, продукт не тронут, два прогона на неизменном дереве совпадают.

## Прогон

Два официальных прогона 2026-10-30 на неизменном дереве `2ae58a5` (пин пре-регистрации `85ab05c`),
носитель `lab/logs/e0155-all.log`. Каждый прогон: PRE_FIX — `git worktree` пина, базы там нет
(`PRE_FIX_BASELINE=none`), 19 находок, код 1; POST_FIX — рабочее дерево, `EF_TABLES=59`,
`EF_SAME=40`, `EF_CHANGED=10`, `EF_ABSENT=9`, `EF_BASELINE_ROWS=19`, `EF_BASELINE_DEFECTS=none`,
`EF_FINDINGS=0`, код 0; `--strict-all` — 19 находок, код 1. Посадки: подменённый байт `e0155.tsv`
(код 1, назван), удалённая таблица (код 1, названа), мёртвая строка базы (код 1, названа), вне git
(код 2, `EF_ROOT_KIND=no-git`). Самопроверка прибора `6/6/0`; мета-страж `H-0151` `GSE_FINDINGS=0`;
соседние стражи (`REFS`, `REVIEW`, `CLAIMS`, `CONTOURS`, `STATUS`, `TEXT`) — коды 0; продукт не
тронут (`RUST_TOUCHED=0`, `WIRE_TOUCHED=0`); диск 13 288 и 13 237 МБ.

## Результат

`supports` по носителю; карточка остаётся **OPEN**: полная верификация `workspace-verify` в этом
цикле не запускалась — свободное место ниже линии владельца (15 000 МБ), тяжёлые прогоны запрещены.
Закрытие ждёт прогона `bash lab/workspace-verify.sh E-0155` и блока контура; до этого вердикт
носителя не переносится в закрытие. `ОЖИДАНИЙ=44 РАСХОЖДЕНИЙ=0` дважды, `WORST_RC=0`, `STABLE=1`.

Граница: страж сверяет файл таблицы, а не её смысл; для будущей карточки с двумя H-файлами под одним
номером правило берёт последний добавленный файл; найденная в первом прогоне самопроверки слепота к
удалённой таблице починена в этом же цикле и записана поправкой в `H-0155`.
