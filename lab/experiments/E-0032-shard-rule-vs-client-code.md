# E-0032 — правило выбора шардов §7.5.1 есть только в стенде гейта; собранный клиент выбирает кластеры

## Гипотеза

См. `H-0032`.

## Стенд (правок измерительного гейта нет)

Новый тестовый файл `crates/vecdht-artifact/tests/fanout_rule.rs`: измеряются два правила на одном
входе — опубликованных строках `reference_artifact()`. Кластерное правило вызывается тем же кодом,
которым его зовёт собранный клиент (`Artifact::centroids.top`), шардово правило реализовано в тесте
как контрольная копия формулировки спеки §7.5.1 (минимум `l2_sq` по 16 строкам шарда, топ-`nprobe`) —
именно потому, что вне `vecdht-embed` такой реализации в коде нет (порог (1)). Никаких правок
`IvfIndex::search`, `Find`, стенда `vecdht-embed/tests/p0_real_corpus.rs` или гейтных порогов нет;
запросы — детерминированный LCG, 256 штук, `i8`-векторы длины `DIM`. Сборка `-j 2` (идёт `E-0027`).
