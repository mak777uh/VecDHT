# E-0061 — байтовая неканоничность кадра приёмки: хвост после подписи против одноразовости; непокрытые `WrongKind`/`Malformed` (§5.1, §5.2, §12.3)

## План прогона

Оракул `crates/vecdht-node/tests/frame_byte_mutation.rs`, helper `lab/e0061-run.sh`
(структура секций как в зелёных `e0058`/`e0059`/`e0060`: BUILD `--no-run` → RUN
`--nocapture` → ИНВЕНТАРЬ → КОНТРОЛЬ `-p vecdht-node`; helper исполняет команду целиком —
урок `e0049`). Харнес — одиночный primary, живой приём бакета 0 из-под `Find`; мутации —
сырые байты кадра (хвост после подписи, инверсия байта подписи, инверсия байта тела,
усечение, `sig_len` 63/65, `flags` 0x0003, `version` 7, `kind` 0xFE, `kind` = `Publish`
с честным телом и честной/пустой подписью, заниженный `body_len`). Часы не двигаются:
`now = 5` во всех ветках, чтобы `prune` не вычищал spent-таблицу (урок `E-0060`).
Лог: `lab/logs/e0061-all.log` (append-only). Пороги заморожены в `H-0061` до первого
замера; коммит пре-регистрации пушится до измерений.
